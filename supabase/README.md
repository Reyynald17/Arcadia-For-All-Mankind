# AFM Database Schema

This SQL file sets up the complete database for AFM.

## Instructions

1. Go to Supabase dashboard
2. Navigate to SQL Editor
3. Create a new query
4. Copy and paste the contents of `schema.sql`
5. Run the query

## What's Created

- `agencies` table for player agencies
- `technologies` table for research items
- `vehicles` table for produced spacecraft
- `missions` table for launched missions
- `logs` table for activity tracking
- `npcs` table for non-player agencies

## Seeding Data

After running the schema, seed initial technologies using the commands in README.md.
